# Подключение базы (Supabase) — один раз, ~10 минут

Без базы сайт работает в «локальном режиме»: всё хранится в одном браузере.
С базой: ученицы занимаются со своих устройств, вы назначаете им наборы и видите их прогресс, а озвучка Mistral сохраняется для всех.

## 1. Создать проект
1. Зайдите на https://supabase.com → **Start your project** → войдите через GitHub.
2. **New project**: имя `moonquest`, придумайте пароль базы (сохраните), регион — Frankfurt. Тариф Free.
3. Подождите 1–2 минуты, пока проект создаётся.

## 2. Создать таблицы
1. Слева **SQL Editor** → **New query**.
2. Откройте файл `supabase/schema.sql` из этого репозитория, скопируйте всё и вставьте.
3. Нажмите **Run**. Должно быть «Success».

## 3. Создать вход для учителя
1. Слева **Authentication** → **Users** → **Add user** → **Create new user**.
2. Ваш email и пароль, галочка **Auto Confirm User** → **Create user**.

## 4. Передать адрес базы сайту
1. Слева **Project Settings** (шестерёнка) → **API** (или **Data API**).
2. Скопируйте **Project URL** и ключ **anon public** (НЕ `service_role`!).
3. Пришлите их Claude — или сами вставьте в файл `config.js`:
   ```js
   window.MQ_CONFIG = {
     supabaseUrl: 'https://xxxx.supabase.co',
     supabaseKey: 'eyJhbGciOi...',
   };
   ```
Ключ `anon public` можно публиковать: доступ ограничен правилами базы.

## 5. Готово
- Откройте сайт → 👩‍🏫 вверху → войдите своим email и паролем.
- **Ученицы**: добавьте имена и учебник для каждой.
- **Наборы карточек**: сфотографируйте/вставьте лексику → ✨ Распознать с ИИ → проверьте → назначьте ученице.
- **Настройки**: ключ Mistral (хранится только в вашем браузере) → 🔊 Проверить голос → 🔊 Озвучить все юниты.
- Ученица открывает сайт, выбирает своё имя — и видит свои задания.

## 6. Обновления базы (если база уже создана)
Выполните по очереди в **SQL Editor → New query → Run** (каждый файл один раз):
- `supabase/002_update.sql` — коды учениц и расписание карточек Anki;
- `supabase/003_cards.sql` — текущий юнит ученицы, карточки, прикреплённые к юниту, карточки от учениц.
- `supabase/004_security.sql` — защита: ученицы сохраняют прогресс и свои слова только со своим кодом, лимит неверных кодов (5 за 10 минут), дневной лимит ИИ.
- `supabase/005_pin_login.sql` — вход только по коду: имён учениц на сайте не видно, их не прочитать из базы без входа учителя; лимит 15 неверных кодов за 10 минут.
- `supabase/006_lessons.sql` — «Уроки по учебнику»: ученицы могут записывать устные ответы (файлы попадают в папку `rec/`). После этого заново разверните функцию `cards-ai` (в ней появился режим урока): Supabase → Edge Functions → cards-ai → вставьте новый код из `supabase/functions/cards-ai/index.ts` → Deploy.

## 7. ИИ-карточки для учениц (без ключа в их браузере)
Ученицы тоже могут нажать «✨ Make cards». Для этого ключ ИИ хранится в Supabase, а не на сайте.
1. Supabase → слева **Edge Functions** → **Deploy a new function** → **Via Editor**.
2. Имя функции: `cards-ai`.
3. Удалите пример кода и вставьте всё из файла `supabase/functions/cards-ai/index.ts` → **Deploy function**.
4. Откройте функцию → **Details** (или Settings) → выключите **Enforce JWT verification** (Verify JWT) → Save.
   Это нужно, чтобы функцию могли вызывать ученицы без входа.
5. Слева **Edge Functions → Secrets** → **Add new secret**: одно из (и по желанию `AI_DAILY_LIMIT` — сколько запросов к ИИ в день, по умолчанию 200)
   - `ANTHROPIC_API_KEY` = ключ Claude,
   - `OPENAI_API_KEY` = ключ OpenAI,
   - `MISTRAL_API_KEY` = ключ Mistral.
6. Готово: на сайте ученица → «＋ Add my words» → пишет слова или фотографирует страницу → «✨ Make cards».
   Без функции кнопка тоже работает, просто перевод ученица вписывает сама.
