# Подключение базы (Supabase) — один раз, ~10 минут

Без базы сайт работает в «локальном режиме»: всё хранится в одном браузере.
С базой: ученицы занимаются со своих устройств, вы назначаете им наборы и видите их прогресс, а озвучка Mistral сохраняется для всех.

## 1. Создать проект
1. Зайдите на https://supabase.com → **Start your project** → войдите через GitHub.
2. **New project**: имя `moonquest`, придумайте пароль базы (сохраните), регион — Frankfurt. Тариф Free.
3. Подождите 1–2 минуты, пока проект создаётся.

## 2. Создать таблицы
1. Слева **SQL Editor** → **New query**.
2. Откройте файл `supabase/schema.sql` из этого репозитория, скопируйте всё и вставьте.
3. Нажмите **Run**. Должно быть «Success».

## 3. Создать вход для учителя
1. Слева **Authentication** → **Users** → **Add user** → **Create new user**.
2. Ваш email и пароль, галочка **Auto Confirm User** → **Create user**.

## 4. Передать адрес базы сайту
1. Слева **Project Settings** (шестерёнка) → **API** (или **Data API**).
2. Скопируйте **Project URL** и ключ **anon public** (НЕ `service_role`!).
3. Пришлите их Claude — или сами вставьте в файл `config.js`:
   ```js
   window.MQ_CONFIG = {
     supabaseUrl: 'https://xxxx.supabase.co',
     supabaseKey: 'eyJhbGciOi...',
   };
   ```
Ключ `anon public` можно публиковать: доступ ограничен правилами базы.

## 5. Готово
- Откройте сайт → 👩‍🏫 вверху → войдите своим email и паролем.
- **Ученицы**: добавьте имена и учебник для каждой.
- **Наборы карточек**: сфотографируйте/вставьте лексику → ✨ Распознать с ИИ → проверьте → назначьте ученице.
- **Настройки**: ключ Mistral (хранится только в вашем браузере) → 🔊 Проверить голос → 🔊 Озвучить все юниты.
- Ученица открывает сайт, выбирает своё имя — и видит свои задания.
