# 🌙 Moonquest

Сайт с интерактивными играми по английскому для учениц (Academy Stars 2 и Academy Stars 4, подготовка к ВПР 4 класса).

Работает без сервера и сборки: достаточно открыть `index.html` или опубликовать через GitHub Pages.

## Игры
| Игра | Что тренирует |
|---|---|
| 🃏 Word cards | карточки: слово, картинка, озвучка, перевод на обороте |
| 👂 Listen and choose | услышать слово и выбрать картинку |
| 🧠 Find pairs | «мемори»: слово ↔ картинка |
| 🔤 Spell the word | собрать слово из букв (правописание) |
| ✏️ Choose the right word | грамматика: выбор формы с подсказкой-правилом |
| 🧩 Make a sentence | собрать предложение из слов |

После каждой игры: звёзды и кнопка «повторить ошибки». Прогресс хранится в браузере ученицы.

**🎥 Zoom lesson** (кнопка вверху): крупный шрифт, счёт «ученица против учителя» по очереди и кнопка учителя «Show answer».

## ✍️ My lists: свои списки слов и неправильных глаголов
Главная → **My lists** → **Новый список**. Вставьте список, по одному слову или глаголу на строку:

- глаголы: `go - went - gone` (можно через пробел, `/`, с переводом: `go went gone идти`);
- слова: `apple - яблоко 🍎` (перевод через `-`, `=` или `:`, эмодзи-картинка по желанию).

Игры для глаголов: Verb cards, Choose the form (с «ловушками» вроде *goed*), Write the forms, Spell the form, Verb pairs.
Игры для слов: карточки, Listen and choose, Find pairs, Spell the word.

**🔗 Ссылка для ученицы** копирует ссылку, в которой лежит весь список. Ученица открывает её, и список появляется у неё на сайте.

## Как добавить юнит
Скопировать `data/as2-unit2.js` в новый файл (например, `data/as2-unit3.js`), заменить слова, грамматику и предложения, затем подключить файл в `index.html` строкой `<script src="data/as2-unit3.js"></script>`.

## Публикация
GitHub → Settings → Pages → Deploy from a branch → выбрать ветку и папку `/ (root)`.
